# Servo — RDE Circuit Simulator

This is the simulator-compatible AVR implementation of the Arduino Servo library for the current Arduino Uno / ATmega328P target.

## Public API

- `Servo()`
- `attach(pin)`
- `attach(pin, minPulseUs, maxPulseUs)`
- `detach()`
- `write(angle)` — angles are clamped to 0–180 degrees; values below 544 are interpreted as angles, while 544 and above are pulse widths in microseconds.
- `writeMicroseconds(pulseUs)`
- `read()`
- `readMicroseconds()`
- `attached()`

The library exposes the standard timing constants `MIN_PULSE_WIDTH`, `MAX_PULSE_WIDTH`, `DEFAULT_PULSE_WIDTH`, `REFRESH_INTERVAL`, `MAX_SERVOS`, and `INVALID_SERVO`.

## Simulator behavior

- Servo pulses are generated by Timer1 compare interrupts.
- Up to 12 Servo objects can be allocated; each attached servo is scheduled in the 20 ms refresh frame.
- On the Uno target, valid digital pins are D0–D13 and A0–A5 (digital pin numbers 14–19).
- Timer1 is reserved while a Servo is attached. This conflicts with other code/libraries that need Timer1, and hardware PWM on D9/D10 should not be expected to work normally at the same time.
- Servo power and mechanical load are not electrically simulated by this library. The Servo signal pin is what the firmware drives.

## Examples

See `examples/BasicServo/BasicServo.ino`, `examples/ServoSweep/ServoSweep.ino`, and `examples/MultiServo/MultiServo.ino`.

## Scope and verification

This implementation targets the AVR Uno simulator. It is not a drop-in implementation for every Arduino architecture (ESP32, SAMD, mbed, etc.). The source has been updated in the repository, but a fresh Arduino CLI compile and live simulator run are still required to verify the current build/runtime end to end.
